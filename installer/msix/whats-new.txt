Mosaïk 1.0.6 is a round of fixes. Mosaïk no longer stops when an app's own start command holds a letter such as İ (a folder named in Turkish, for one). When your settings or your workspaces cannot be read, Mosaïk says so once, in plain words, and goes back to the copy it keeps, which is now one change behind at most instead of as old as Mosaïk's last start; a file saved with a byte order mark is read. A workspace whose file was edited by hand is mended and said once, and picking a layout for it no longer leaves Mosaïk busy for good. Screen readers hear a note as it arrives, and in menus the Up, Home and End keys go where they should. From 1.0.5: Rate Mosaïk, in About and in the tray menu, opens Mosaïk's page in the Microsoft Store.
